## Featured Projects
### Smart Traffic Light Controller
This Dynamic Density & Time-Threshold Traffic Light Controller optimizes intersection management by moving away from fixed-timer signals:

- **Traffic Simulation:** Initializes each lane with a randomized queue of vehicles using the `random` library to emulate real-world traffic variance.
- **Density-Based Scheduling:** Dynamically prioritizes signal green times for the lane carrying the highest current vehicle count to clear congestion fast.
- **Starvation Prevention (Max-Wait Threshold):** Tracks total elapsed red-light duration per lane. If a low-density lane reaches a maximum waiting threshold, the system overrides pure density scheduling to grant it dynamic green light priority, preventing indefinite delays.
- **Tech Stack:** Libraries & Modules: `random` (vehicle generation), `time` / `threading` (signal timing & tracking)
